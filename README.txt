Little Steps Learning v2.0

Files:
- index.html: app interface and learning activities
- manifest.webmanifest: installable web app settings
- icon.svg: app icon
- sw.js: offline cache and update handling

Publish with GitHub Pages:
1. Open your public GitHub repository.
2. Upload these four files to the repository root, replacing the existing files.
3. Commit the changes to the main branch.
4. GitHub Pages should redeploy automatically.
5. Open your existing GitHub Pages URL. If an older version remains, close the tab and reopen, or refresh after a minute.

The app does not use accounts, ads, chat, external libraries, or remote data collection. Quiz score and activity state are kept only in the current page session. Speech pronunciation depends on the voices available on the device/browser.
